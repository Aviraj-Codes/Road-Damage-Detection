# Model weights

Place the trained `best.pt` checkpoint here as `models/best.pt` for the Streamlit app and evaluator. Train with `python train.py`; the initial checkpoint is saved under `runs/detect/road_damage/weights/best.pt`.

Model weights are intentionally not bundled before training. Record the model architecture, training dataset version, class order, and evaluation split with any checkpoint you add. Check the source dataset and pretrained-weight licenses before redistribution.
